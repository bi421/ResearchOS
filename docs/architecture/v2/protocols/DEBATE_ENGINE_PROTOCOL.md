\# ResearchOS v2 — Debate Engine Protocol



Version: 2.0

Status: Architecture Design



\---



\# 1. Purpose



Debate Engine provides internal challenge and adversarial evaluation.



Its purpose is to prevent premature conclusions and improve intelligence reliability.



Debate Engine does not create decisions.



It challenges reasoning before decisions are produced.



\---



\# 2. Debate Philosophy



Every important hypothesis must survive:



\- supporting analysis

\- opposing analysis

\- evidence challenge

\- confidence review





A conclusion that cannot survive challenge is considered unstable.



\---



\# 3. Debate Process



INPUT:



Reasoning Object





PROCESS:



1\. Receive hypothesis



2\. Generate supporting arguments



3\. Generate opposing arguments



4\. Compare evidence strength



5\. Evaluate contradictions



6\. Produce debate result





OUTPUT:



Debate Result





\---



\# 4. Debate Roles





\## Analyst



Responsibility:



Create the strongest possible explanation.



Produces:



\- hypothesis

\- supporting evidence

\- reasoning path





\---



\## Challenger



Responsibility:



Attempt to disprove the hypothesis.



Produces:



\- weaknesses

\- missing evidence

\- alternative explanations





\---



\## Validator



Responsibility:



Evaluate evidence quality.



Checks:



\- source reliability

\- consistency

\- reproducibility





\---



\## Judge



Responsibility:



Evaluate final debate outcome.



Produces:



\- winning explanation

\- confidence score

\- unresolved uncertainty

\# 6. Debate Rules





\## Rule 1



Every major conclusion requires challenge.





\## Rule 2



Opposing evidence must be considered.





\## Rule 3



Confidence decreases when contradictions exist.





\## Rule 4



Unresolved conflicts must remain visible.
