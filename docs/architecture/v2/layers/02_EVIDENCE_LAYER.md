# ResearchOS v2 — Evidence Layer Architecture

Version: v2.0
Layer: 02 / 10

## Purpose

Convert observations into verifiable evidence.

## Responsibilities

- collect evidence
- classify evidence
- attach provenance
- measure confidence

## Evidence Types

- empirical
- statistical
- experimental
- historical
- external

## Rules

No claim without evidence.
No evidence without source.
No result without reproduction path.
