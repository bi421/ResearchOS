# ResearchOS Documentation Archive

**Purpose:**
Historical record of the ResearchOS architecture evolution. This archive preserves
planning documents, audit reports, architecture reviews, completed task reports,
historical TODOs, and deprecated design documents. It is **read-only** — a historical
record. Do not modify or delete archived files.

**Active documents remain in place:**
- `docs/ARCHITECTURE_FREEZE_V2.md` — the current architecture constitution (governing doc).
- `docs/ARCHITECTURE_INVARIANTS.md` — current active architecture invariants.
- `README.md` (root) — current repository overview.
- `AI_CONTEXT.md` (root) — current developer/AI context helper.
